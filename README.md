# LikelyAI

LikelyAI is a personal Android app prototype for detecting likely AI-generated content on-device. It is built for a personal use case and focuses on broad detection, privacy, and local-only processing.

## Features
- Personal phone-first Android app
- Local-only detection engine
- Overlay warning when likely AI is detected
- Notification alerts
- Local history of detections
- Sensitivity controls

## Current status
This is a starter app foundation, not a production deepfake detector. It is designed to be improved over time for real personal use on Android.

## How to run
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Connect an Android device or start an emulator.
4. Run the app.
5. Grant overlay and notification permissions when prompted.

## Notes
- This app is intentionally privacy-first.
- It does not upload content to a server.
- It is built as a personal utility, not a public product.
